01 · Caso de estudio

La Feria 16 de Julio reúne diferentes actividades comerciales. Este proyecto analiza un caso hipotético representativo de cuatro sectores y cómo distribuir recursos ante cambios en las necesidades financieras. El presupuesto, las ponderaciones y las necesidades utilizados son datos simulados con fines académicos; no representan mediciones oficiales ni un presupuesto común de toda la feria.

02 · Formulación matemática

Se definen x₁, x₂, x₃, x₄ como recursos destinados a los cuatro sectores, expresados en miles de bolivianos. Se minimiza la desviación respecto de las necesidades objetivo dᵢ y se penaliza la diferencia respecto del presupuesto de referencia B.

J(x) = ½ Σ wᵢ(xᵢ − dᵢ)² + (λ/2)(Σ xᵢ − B)²

Al imponer ∇J(x)=0 se obtiene el sistema lineal:

A x = b,   A = diag(w₁,w₂,w₃,w₄) + λ 11ᵀ,   bᵢ = wᵢdᵢ + λB

Propiedad SPD

Si wᵢ > 0 y λ > 0, A es simétrica y definida positiva porque para z ≠ 0:

zᵀAz = Σ wᵢzᵢ² + λ(Σzᵢ)² > 0

Algoritmos implementados

GC: gradiente conjugado clásico. GCP: gradiente conjugado con precondicionador de Jacobi, M = diag(A). Referencia: factorización de Cholesky A = LLᵀ.

Criterio de parada: ‖b − Ax‖₂ / ‖b‖₂ ≤ 10⁻⁶; x₀ = 0; máximo 100 iteraciones.

El presupuesto se aplica como penalización, no como restricción exacta. Por ello, la suma de las asignaciones puede diferir ligeramente de B.

05 · Procedimiento iterativo paso a paso

Los valores de cada iteración se calculan en el navegador. Se muestran α, β, norma del residuo y residuo relativo para ambos métodos.

Gradientes conjugados (GC)

Gradientes conjugados precondicionado (GCP)

Fórmulas utilizadas

GC
r₀ = b − Ax₀; p₀ = r₀
αₖ = (rₖᵀrₖ)/(pₖᵀApₖ)
xₖ₊₁ = xₖ + αₖpₖ
rₖ₊₁ = rₖ − αₖApₖ
βₖ = (rₖ₊₁ᵀrₖ₊₁)/(rₖᵀrₖ)
pₖ₊₁ = rₖ₊₁ + βₖpₖ
GCP
M = diag(A); zₖ = M⁻¹rₖ
p₀ = z₀
αₖ = (rₖᵀzₖ)/(pₖᵀApₖ)
xₖ₊₁ = xₖ + αₖpₖ
rₖ₊₁ = rₖ − αₖApₖ
βₖ = (rₖ₊₁ᵀzₖ₊₁)/(rₖᵀzₖ)
pₖ₊₁ = zₖ₊₁ + βₖpₖ

07 · Conclusiones del experimento

El método GCP puede mejorar la estabilidad numérica y la rapidez de reducción del residuo en ciertos problemas mal condicionados. No se garantiza que siempre necesite menos iteraciones que GC: el comportamiento depende de la matriz y del precondicionador.
